# 📊 Mutual Fund Data Analytics & Power BI Dashboard

## 📌 Project Overview

This project analyzes **mutual fund data** using **Python, SQL, SQLite, and Microsoft Power BI**.

The project provides interactive insights into **mutual fund industry trends, fund performance, investor transactions, SIP inflows, category-wise inflows, and market trends** through an interactive Power BI dashboard.

---

## 🎯 Project Objectives

The main objectives of this project are:

- **Analyze mutual fund industry AUM and folio trends**
- **Compare mutual fund performance and risk**
- **Analyze investor transactions and investment behavior**
- **Study monthly SIP inflows**
- **Analyze category-wise inflows**
- **Compare SIP trends with market benchmark performance**
- **Build an interactive Power BI dashboard**
- **Generate meaningful insights from financial data**

---

# 📊 Power BI Dashboard

The Power BI dashboard consists of **four analytical pages**, each focusing on a specific area of the mutual fund industry.

---

## 1️⃣ Industry Overview

The **Industry Overview** page provides a high-level view of the mutual fund industry.

### **Key Metrics**

- **Total AUM**
- **SIP Inflows**
- **Total Folios**
- **Total Schemes**

### **Visualizations**

- **Industry AUM Trend**
- **AUM by Fund House**
- **Monthly SIP Inflow Trend**
- **Industry Folios Trend**

### **Purpose**

This page helps understand the **overall growth and trends of the mutual fund industry**.

---

## 2️⃣ Fund Performance

The **Fund Performance** page focuses on analyzing mutual fund returns and risk.

### **Analysis Includes**

- **Return vs Risk Analysis**
- **Performance Scorecard**
- **NAV vs Benchmark Trend**

### **Filters**

- **Fund House**
- **Category**
- **Plan**

### **Purpose**

This page allows users to **compare fund performance and understand the relationship between returns and risk**.

---

## 3️⃣ Investor Analysis

The **Investor Analysis** page focuses on investor transactions and investment behavior.

### **Key Metrics**

- **Total Transactions**
- **Total Investment**
- **Total Redemption**
- **Average Transaction Amount**

### **Visualizations**

- **Transaction Amount by State**
- **Transaction Type Split**
- **Age Group vs Average SIP Amount**
- **Monthly Transaction Volume**

### **Purpose**

This page provides insights into **investor activity, transaction patterns, and investment behavior**.

---

## 4️⃣ SIP & Market Trends

The **SIP & Market Trends** page analyzes SIP inflows and their relationship with market performance.

### **Analysis Includes**

- **SIP Inflow vs Nifty 50 Trend**
- **Category Inflow Heatmap**
- **Top 5 Categories by Net Inflow — FY25**

### **Purpose**

This page helps analyze **SIP growth, category-level investment trends, and SIP inflows compared with Nifty 50 market performance**.
